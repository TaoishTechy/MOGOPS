## Priority Repairs for v2.8

### Repair 1 – Remove Double‑Counting (Critical)
- Remove `LTD_eff` from CSP definition.
- Define `CSP_base` as aggregate of all other stress terms.
- Master risk numerator = `CSP_base + LTD_eff + EPE + MA + NFR`.

### Repair 2 – Timestep Separation for PR (Critical)
- `PR(t) = f( state(t-1) )` – break circular dependency.
- Use standard lag‑1 dynamical systems approach.

### Repair 3 – Variable Class Separation (High)
- **Core risk variables** – directly enter master equation.
- **Mode classifier variables** – determine collapse fingerprint.
- **Recovery variables** – post‑collapse outcomes.
- **Sacred geography variables** – geometric analysis only.

### Repair 4 – Confidence‑Weighted Uncertainty Bands (High)
- Report risk as `Risk ± confidence_interval` (e.g., `1.32 ± 0.24`).
- Confidence = f(observer class, data quality, sensitivity).

### Repair 5 – Variable Provenance Tags (High)
Each variable must carry metadata:
```json
{
  "source": "archaeological / historical / ethnographic / modeled",
  "confidence": 0.85,
  "temporal_resolution": "annual",
  "spatial_resolution": "regional",
  "calibration_cases": ["Maya", "Aztec"]
}
```

### Repair 6 – Transformation Outcome Categories (Medium)
Replace binary collapse/survival with 7 categories:
1. Terminal collapse  
2. Elite collapse  
3. Urban contraction  
4. Regional transformation  
5. Survivor adaptation (Type VI)  
6. Continuity  
7. False positive  

### Repair 7 – Interpretability Functions (High)
- `validate_inputs()` – checks completeness, ranges, consistency.
- `explain_risk_contribution()` – decomposes total risk into variable contributions.

### Repair 8 – Auto‑Auditing System (High)
Automatically run upon every calibration or model change:
- Survival controls  
- Null cases  
- Ablation tests  
- Sensitivity analysis  
- Holdout validation  

Generates a quality assurance report.
